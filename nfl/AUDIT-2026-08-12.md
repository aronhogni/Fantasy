**Skrár:** `src/DraftBoard.jsx:117`, `:131`, `:1045`, gegn `:673-687`.

`onPicks` fær **aðeins þau vol sem porast við borðið**:

```js

  const known = byId.has(pid);
  if (known) { ids.push(pid); … }
  else { unknown++; … }        // TALIN, en EKKI í `taken`

```

og valnúmerið er svo `cur = taken.size + 1`. Appið **veit** um óporuðu volin —
það birtir „N picks are not on this board" (`:881`) — en telur þau ekki með.
`taken.size` vanáætlar valnúmerið um `unmatched.total` nákvæmlega.

Afleiðingin er tvíþætt og **magnast með F1**:

* `nextOwnPick(cur, …)` getur skilað vali sem er **þegar liðið**: 27 vol tekin,
  2 óporuð → `taken.size = 25`, `cur = 26`, `nextOwnPick(26,10,7) = 27` — en val
  27 er farið. Borðið litar gegn vali í fortíðinni.
* `picksUntilNext(cur, teams)` **leiðir sætið út af `cur`**, svo skekkjan
  breytir ekki bara tölunni heldur *sætinu*: 20 vol, 3 óporuð → `cur = 18` →
  afleitt sæti 3 → „Your next pick is 23, 5 picks away" í stað 27/6.

Sama gildir um `nfl_taken:<id>` sem er óþvingað að innan (F26b): `[4034,6794]`
(tölur í stað strengja) gaf **„2 drafted · Pick 3"** og **engan strikaðan út**.

`tests/sleeper.mjs:338` staðfestir aðeins að strengurinn „not on this board"
birtist; ekkert ber hann við valnúmerið.

**Hvað ég myndi gera:** `cur = picks.length + 1` (heildarfjöldi vola úr
Sleeper-svarinu), ekki `taken.size + 1`. `taken` er *mengi leikmanna sem má
strika út*; það er ekki *teljari vola*.
